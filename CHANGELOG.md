# Love Island changes

## 0.1.0 — experimental

- Persistent top capsule, hover expansion, notification history and media controls.
- Foreground-only FIFO countdowns, OSD interruption, DND/lock/fullscreen suppression and primary-output observation.
- Separate queue, playback, desktop adapters and QML presentation state.
- Continuous size animation; accepted 450/430ms closing timings. Stable 144 FPS remains unresolved.
- Arch package with account-scoped activation, login startup, persistent disable and removal recovery.
- Chinese README, English installation instructions and isolated behavioral tests.
